AURA Fashion - Website bán thời trang nam/nữ (Bootstrap 5)

Cấu trúc thư mục:
  index.html      -> cấu trúc trang (HTML)
  css/style.css   -> giao diện (CSS)
  js/main.js      -> chức năng (JavaScript)
  images/         -> toàn bộ hình ảnh (SVG)

Cách chạy: mở file index.html bằng trình duyệt (cần có Internet để tải Bootstrap, Bootstrap Icons, Google Fonts từ CDN).

Thay ảnh thật: chép ảnh .jpg/.png vào thư mục images, rồi sửa đường dẫn src trong index.html
(sản phẩm cũng cần sửa thuộc tính data-img của nút "Thêm vào giỏ").
